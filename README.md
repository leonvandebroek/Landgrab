# VirtuBattle

A game people play outside with their phones, battling each other virtually in the real world.

Work is in the proof-of-concept phase: an iOS app and a small .NET server to test real-world
positioning, aiming and close-range UWB play.

| Folder | What |
| --- | --- |
| [`ios/`](ios/README.md) | SwiftUI iPhone app (Xcode project generated with XcodeGen) |
| [`server/`](server/README.md) | ASP.NET Core SignalR game server |

## Archived: Landgrab

The previous project in this repository, **Landgrab** (a real-world hex territory game),
has been moved to [`archive/landgrab/`](archive/landgrab/ARCHIVE.md). It is kept as
reference material only and is not built, tested or deployed.
